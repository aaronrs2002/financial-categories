Vanilla JavaScript Budget App | Categories, Percentages & Charts




In this 10-minute JavaScript tutorial, I walk through the functionality behind a budget and expense tracking application built with vanilla JavaScript. Users can enter individual expenses by name, cost, and category, which are stored as JavaScript objects and saved to localStorage as JSON. The application dynamically organizes expenses by category, calculates category totals, and determines the percentage each individual item represents within its category. I also demonstrate how the data is transformed into series and labels for an ApexCharts donut chart, providing a visual breakdown of spending across categories. The tutorial covers dynamically generating HTML, working with arrays and objects, calculating percentages, adding and deleting expenses, rebuilding the interface as data changes, and persisting information with localStorage. I also walk through the application's JSON download and upload functionality, allowing users to save their budget data to a file and restore it later.
